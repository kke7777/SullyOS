# 日程与情绪独立设置

聊天的日程/情绪面板提供两个独立开关，3D 家园对话共用角色设置和上下文构建逻辑。

- 仅日程开启：生成日程；每轮提供完整活动表、当前/下一时段和允许调整日程的说明。不会运行情绪评估或注入缓存 Buff、innerState。
- 仅情绪开启：照常评估并注入情绪，完全不依赖日程或日程风格。
- 两者同时开启或同时关闭，分别按各自开关执行。

日程不再生成早、午、晚三段 flowNarrative，也不保存模型额外返回的 slot.innerThought。旧备份保留兼容字段，但聊天、家园、桌面、小剧场与云端日程渲染均不读取这些独白；上传的新云端日程也不携带它们。

emotionConfig.independent 标记一次性迁移完成。旧数据按升级前实际开关状态迁移，避免原本关闭日程的角色意外启用情绪评估；迁移后的日程切换不改变情绪。新角色两个功能默认关闭。关闭情绪保留配置与缓存，重新开启后可继续使用。

情绪评估自身的提示词和 innerState 保持原有用途，仅在情绪开关开启时参与聊天与家园上下文。
