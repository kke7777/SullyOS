# 本版本移除的聊天功能

## 心象

移除聊天与协同工作入口、心象设置和装扮编辑、历史/流式/通话/协同卡片。
聊天、通话、主动消息模板和协同请求不再注入心象提示词，也不根据旧设置
额外请求 extended thinking、修改模型名或追加 reasoning_effort。
客户端不再保存新的心象内容，Worker 不再将思考内容附加到即时消息推送。
仍剥离模型正文中的 think 标签，保持普通正文和文件交付可用。

## 智能语境 / 交流增强

移除总开关、角色交流步伐设置，以及 M2/M3 分析模块、谈话参与原则和候选策略。
语境、节奏、深度和谈话参与指导不再进入私聊或 3D 家园请求。
运行时将旧配置中的 recallRouter、interactionAdaptation、deepEngagement 归为 false，
旧备份或已保存的开启状态不能恢复这些功能。正常记忆召回、门牌、归档、世界书
和用户定稿的普通聊天/共享表达规则继续走原有路径。

## 旧数据兼容

保留旧角色、消息与装扮的字段格式以支持读取备份，不删除历史消息或记忆。
旧心象内容隐藏，旧心象作品不能重新安装成有效功能。
模型自身的推理能力由所选模型/API 决定；本次移除的是应用提供的心象功能。

验证包括生产构建和禁止 TCP 连接的本地回归测试，覆盖旧设置、历史消息、
聊天/家园提示词、协同工作、通话正文解析和后台推送/收件。
